# 🚨 Smart Gas Leak Detection and Instant Alert System

## Project Overview

The **Smart Gas Leak Detection and Instant Alert System** is an IoT-enabled safety solution designed to detect hazardous gas leaks in real-time and provide immediate alerts to users through GSM communication. The system utilizes an **MQ-5 Gas Sensor** to continuously monitor gas concentrations and an **Arduino Uno** to process sensor data and control alert mechanisms.

When a gas leak is detected beyond a predefined threshold, the system activates an audible alarm through a buzzer, displays warning messages on an LCD screen, and sends instant notifications via the **SIM900A GSM Module**. This project enhances safety in residential, commercial, and industrial environments by enabling rapid response to potentially dangerous gas leak situations.

## Working Principle

1. The **MQ-5 Gas Sensor** continuously monitors the surrounding environment for combustible gases.
2. Sensor readings are processed by the **Arduino Uno**.
3. When the detected gas concentration exceeds the predefined safety threshold, the system identifies it as a potential gas leak.
4. The **buzzer** is activated immediately to provide an audible warning.
5. The **16×2 LCD** displays a gas leak alert message.
6. The **SIM900A GSM Module** sends an instant notification to a predefined phone number.
7. The system continues monitoring and alerting until the gas concentration returns to a safe level.
